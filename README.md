Lowline is a free, local-first form editor for Windows. You write the forms you fill in again and again as plain notes; each filled-in form is a file in a folder you choose. It is being built to learn from the entries you confirm and suggest the fields that call for judgment — you always make the final choice.

## Download

No release has been published yet. When one is, it will be at
[Latest release](https://github.com/iyulab/lowline-releases/releases/latest) — `Lowline_<version>_x64-setup.exe`.

## System requirements

- Windows 10 or 11 (x64)
- No administrator rights needed — Lowline installs for the current user.
- No internet connection, account, graphics card or AI model is needed. Your documents stay in the folder you choose.
